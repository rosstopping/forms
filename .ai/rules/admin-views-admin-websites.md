# Admin Views Admin Websites

## Include health reports and Search Console in Essential
Essential, including an active onboarding trial, includes manual/scheduled website health reports and Google Search Console access. Search opportunities and paid SEO APIs, Pixel, content automation, and GitHub remediation remain higher-tier or admin-only. Enforce active entitlement server-side so access ends when the membership or trial expires.

## Growth trials include SEO performance
Onboarding trials have normal Growth entitlements, including Growth-gated SEO performance UI. Health reports and Search Console remain available from Essential upward. Paid DataForSEO snapshots stay disabled by default and opt-in per website.
