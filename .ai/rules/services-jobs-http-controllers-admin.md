# Services Jobs Http Controllers Admin

## SEO reruns preserve history and report SERP freshness
A rerun creates a new search linked to the original. Reuse the provider-neutral seven-day SERP cache unless an admin explicitly forces fresh results. Cached results have zero provider cost and no paid API-usage row; persist and display per-keyword source and fetched time.

## Competitor audits remain on demand and evidence-backed
Competitor audits are explicitly requested per website/domain/market and reuse seven-day results; rendering pages and content generation must never trigger paid competitor research. Preserve stage checkpoints and API costs across retries. Missing keywords require provider comparison evidence, not absence from local samples. Only fetched page evidence may support briefs; ranking causes remain hypotheses. Automatic generation uses recent, relevant, non-excluded saved findings; explicit briefs retain a snapshot and deduplicate per website/market/primary keyword. Keep delivery review-first.

## AI Visibility uses genuine opt-in provider observations
AI Visibility is a first-class website section. Dashboard/report reads never invoke providers. Queue opt-in checks through the existing weekly ranking dispatcher; no separate AI email or scheduler. Label OpenAI API observations OpenAI, never ChatGPT; unavailable providers stay disabled. Only completed checks enter appearance/citation percentages. Preserve prompt, identity, model and methodology evidence, suppress comparisons when successful coverage changes, and never infer list positions or citation domains.
