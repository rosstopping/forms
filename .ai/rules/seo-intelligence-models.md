# Seo Intelligence Models

## Produce honest actions for sparse SEO samples
Run the standard evidence thresholds first. When stored keywords exist but none qualify, create a small set of foundation opportunities from the strongest observed terms, mark metrics with uses_adaptive_threshold=true, and describe them as coming from a limited sample. Never invent volume, movement, or ranking evidence. A refresh may derive these locally from a recent empty snapshot without another provider call.
