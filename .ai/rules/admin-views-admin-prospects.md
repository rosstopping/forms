# Admin Views Admin Prospects

## Keep the main outreach list inclusive
The default outreach/dashboard prospect list and its searches include all non-deleted temperatures and lifecycle stages, including contacted and replied prospects. Only explicit Hot, Warm and Replies tabs narrow the list. Keep the bulk-selection hidden filters aligned with the visible query; never silently limit the default list or its bulk actions to cold prospects.
