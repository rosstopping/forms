# Admin Requests

## Content cadence follows the website subscription
Growth permits one scheduled run per local Monday–Sunday week; Complete permits up to three selected days. Preserve the primary weekday and paused extra days on downgrade; never opt existing sites into extra runs. Managers may edit schedules but must not replace the staff automation creator/credentials. Use ContentSchedule for dispatch, displays and reminders, with one local-date reservation under a plan lock. Automatic work uses queued requests then eligible targets, a 14-day target/known-page cooldown and open-review exclusions; skip empty runs visibly. Manual staff runs are outside the weekly cap but retain date/overlap/review safeguards. Delivery always requires human PR review.
